# 🏦 Bank Management System

The **Bank Management System** is a simple yet functional GUI-based application built using **Python** and **Tkinter**. It allows users to create and manage personal bank accounts with features such as account creation, login authentication, balance inquiry, and fund transactions (credit and debit). This project is ideal for understanding how basic banking operations can be simulated in a desktop application.

---

## 🚀 Features

- 🔐 **Login / Account Creation Interface**  
  Easily create a new account or log in using your credentials.

- 📝 **Account Creation Form**  
  Enter essential details like username, PIN, and opening balance.

- 📊 **Dashboard**  
  A centralized screen for managing your account activities.

- 💰 **Balance Inquiry**  
  View your current account balance at any time.

- 💳 **Basic Banking Functionalities**
  - **Account Creation**: Register with personal information.
  - **Login Authentication**: Secure access using credentials.
  - **Fund Transactions**: Credit or debit money easily.
  - **Transaction Details**: View summaries of recent actions.

---

## 🛠️ Technologies Used

- **Python 3.x**
- **Tkinter** – for the graphical user interface
- **Text Files** – to simulate a database for storing user data
